# Roadmap

## Phase 0 — Repository foundation

Documentation, repository conventions, toolchain, architecture, and handoff process.

## Phase 1 — Application shell

Next.js foundation, shared responsive layout, original visual system, placeholder routes, route states, tests, and CI.

## Phase 2 — Canonical game data

Versioned directories, Zod schemas, loaders, duplicate detection, representative sample data, validation command, and contributor documentation.

## Phase 3 — Unit catalogue

Search, filters, unit cards, detail pages, practical explanations, requirements, version display, related units, and tests.

## Phase 4 — Division builder MVP

Grid, support slots, structural rules, canonical calculations, role selection, transparent simplified evaluation, assumptions, suggestions, and tests.

## Phase 5 — Nation guide MVP

Validated content schema, guide index, nation overview, one complete path, metadata, cross-links, and tests.

## Phase 6 — Shareability

Anonymous URL or server-stored templates and an exportable image or compact code.

## Phase 7 — Accounts and community

Only with explicit approval: database, authentication, profiles, saved and published templates, ratings, reporting, moderation, then comments.

## Phase 8 — Curated news

Only with explicit approval: manual official-source and selected-video workflow. No broad scraping without a separate design review.
